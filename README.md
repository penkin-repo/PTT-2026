# PDF → CMYK TIFF (LZW)

Нативная Windows-утилита для быстрой подготовки **PDF** в **CMYK TIFF (LZW)** с применением ICC-профиля (по умолчанию `USWebCoatedSWOP.icc`). Без сторонних библиотек — один исполняемый файл на .NET Framework 4.8 + Ghostscript.

## Возможности

- **Drag & Drop** (или выбор кликом / передача файлов аргументами) — готовые `.tif` сохраняются в ту же папку рядом с исходными PDF.
- **Автоопределение нативного DPI** — для векторных и гибридных макетов не ниже `300 DPI`, для чистого растра сохраняется исходное разрешение.
- **Симметричная обрезка по краям** — задаётся целевой размер `Ш × В` в миллиметрах (например, `520×620` → `500×600` срезает по `10 мм` с каждой стороны). Пустые поля — без обрезки.
- **Цвет как в Photoshop** — CMYK 32-bit, сжатие LZW, встроенный ICC-профиль, `-sDefaultCMYKProfile`, симуляция оверпринта (по галочке).
- **Префлайт в логе** — предупреждает о переливе краски (`TIL > 305%`) и крупных чёрных плашках `0/0/0/100`.
- **Безопасное усиление чёрных плашек** *(выкл. по умолчанию)* — усиливает только внутреннюю область крупных заливок `0/0/0/100` до `C40 M30 Y30 K100`, не затрагивая мелкий текст, тонкие линии, фото и кромки белых вывороток.
- **Постраничная разбивка** многостраничных PDF и кнопка **«Поверх окон»**.

## Требования

- Windows 10/11 (x64), встроенный .NET Framework 4.8.
- **Ghostscript 64-bit** (`gswin64c.exe`): установленный в `C:\Program Files\gs\` **или** портативно в папке `engine\` рядом с `PdfToTiff.exe` (`gswin64c.exe` + `gsdll64.dll`).
- ICC-профиль (`.icc` / `.icm`) рядом с `.exe` или в папке `profiles\`.

## Сборка

Запустите `build.bat` — он скомпилирует `PdfToTiff.exe` встроенным компилятором `csc.exe` (Visual Studio и SDK не требуются).

Чтобы сменить иконку программы, замените `app.ico` и перезапустите `build.bat`.
